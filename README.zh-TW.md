# PipeTerminal

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md)

PipeTerminal 在視覺化流程編輯器中整合 SSH、SFTP、指令碼執行、建置與部署。

## 下載

從 [GitHub Releases](https://github.com/seemilit/pipeterminal/releases) 或 [Gitee 發行版](https://gitee.com/seemilit/pipeterminal/releases) 下載 `PipeTerminal-Paid-<版本>.exe`。Windows 可攜版可直接執行，預設使用免費功能，輸入有效啟用碼後即可解鎖付費功能。
