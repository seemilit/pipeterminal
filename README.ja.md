# PipeTerminal

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [한국어](README.ko.md) · [Español](README.es.md)

PipeTerminal は SSH、SFTP、スクリプト実行、ビルド、デプロイをビジュアルなワークフローエディターにまとめたツールです。

## ダウンロード

[GitHub Releases](https://github.com/seemilit/pipeterminal/releases) または [Gitee のリリース](https://gitee.com/seemilit/pipeterminal/releases) から `PipeTerminal-Paid-<version>.exe` をダウンロードできます。Windows 用のポータブル版はそのまま起動でき、初期状態では無料機能を利用できます。有効な認証コードを入力すると有料機能が使えるようになります。
