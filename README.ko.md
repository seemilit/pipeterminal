# PipeTerminal

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [Español](README.es.md)

PipeTerminal은 시각적 워크플로 편집기에서 SSH, SFTP, 스크립트 실행, 빌드 및 배포를 지원합니다.

## 다운로드

[GitHub Releases](https://github.com/seemilit/pipeterminal/releases) 또는 [Gitee 릴리스](https://gitee.com/seemilit/pipeterminal/releases)에서 `PipeTerminal-Premium-x64-<version>.zip`을 다운로드할 수 있습니다. 압축을 풀고 `PipeTerminal.exe`를 실행하세요. 기본 모드에서는 무료 기능을 이용할 수 있으며, 유효한 활성화 코드를 입력하면 유료 기능이 열립니다.
