# PipeTerminal

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

PipeTerminal reúne SSH, SFTP, ejecución de scripts, compilación y despliegue en un editor visual de flujos de trabajo.

## Descarga

Descarga `PipeTerminal-Paid-<version>.exe` desde [GitHub Releases](https://github.com/seemilit/pipeterminal/releases) o [Gitee Releases](https://gitee.com/seemilit/pipeterminal/releases). El ejecutable portátil de Windows se puede abrir directamente. Se inicia en modo gratuito y desbloquea las funciones de pago al introducir un código de activación válido.
