# 主页面状态记忆

正常关闭主窗口时，将以下状态保存到 `conf/settings.json` 的 `window` 对象：

- 窗口位置、大小和最大化状态。
- 左侧目录栏宽度与是否隐藏。
- 配置编辑区和下方交互区的分栏尺寸。
- 最后打开的主页面模块。
- 已打开模块各自最后选中的目录记录。

程序启动后，只创建上次打开的主页面，其他页面仍按需加载。之后第一次打开其他模块时，通过 `ModulePage.select_item()` 恢复其选择；不会调用可能启动连接的 `activate_item()`。

主窗口只使用模块 ID 和公共页面接口，不导入具体功能包。删除上次使用的模块后，回退到注册表中第一个顶部模块；删除选中的配置后，保留该页面正常的默认选择。语言、主题、设置等底部弹窗不会自动打开。

下方面板仍在启动时隐藏，不保存或恢复 SSH 连接。用户主动连接后，交互面板使用记忆的分栏高度。在终端模式退出程序时，保存进入该模式前的普通布局，避免下次启动时编辑区或侧栏被记录为零宽度。

“重置布局”恢复现有默认分栏尺寸，下次正常退出后保存默认布局；它不删除服务器配置、日志或历史版本。

`common/settings/store.py` 提供读取及合并保存指定 JSON 区域的基础组件。写入时重新读取文件，保留语言、主题和其他设置，再以临时文件替换原文件。保存失败会使用现有多语言“保存失败”提示，不覆盖原文件。

`common/qt/window_state.py` 负责状态校验、恢复和收集；主窗口只接入加载与正常关闭时的保存。开发运行和便携包使用同一套机制，便携包的配置位于 EXE 同级。

本次仅进行源代码核对，未运行应用、测试或打包。窗口跨屏恢复、最大化、普通模式与终端模式下退出，以及配置删除后的恢复，需要在界面中验收。
