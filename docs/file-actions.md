# 文件右键

菜单能力参考原项目 `ssh/app/qt_ssh_terminal_view.py` 的三个入口，
按当前 SFTP package 重新实现，不导入旧项目。

## 菜单与选择

- 本地列表：上传选中项、打开所在文件夹、复制路径、刷新。
- 远端文件列表：文件夹跳转、编辑普通文件、下载、多选复制/剪切/删除、
  单项重命名、复制路径、粘贴、新建文件和文件夹、上传、上级目录、刷新。
- 目录树：针对所点目录执行打开、复制、剪切、下载、删除、粘贴和新建。
  根目录不允许复制、剪切、下载、重命名或删除，可在其内新建内容。
- 普通文件可修改八进制权限；`.sh/.bash/.zsh` 或有执行位的文件提供执行
  及带参数执行。未压缩的 `.log/.out` 及轮转日志提供 tail、末尾 N 行和 grep。
- 右键未选中项时切换选择，右键已选中项保留多选，空白区域清除选择。
  菜单只读已有元数据，不在 UI 线程查询服务器。菜单回调使用捕获的路径和
  连接，不因目录变化改为操作后来选中的文件。运行时再次验证连接与路径。

- 终端输出中的文件名、路径和提示符目录也可直接右键，不需要按 Ctrl。
  先显示文本复制/粘贴，再后台验证对应路径并追加文件菜单；相对路径使用该行
  输出产生时的目录，历史输出不会错误套用当前目录。命令输入框在路径文字上
  右键保留原有文本菜单，同时追加当前 Shell 目录下的文件操作。
  菜单关闭后取消未完成的验证；只打开菜单不会执行命令或改变目录。
  连续右键保留最新请求，前一个任务退出后自动继续查询；等待期间不更换连接。
  终端菜单的目录跳转及返回上级目录复用现有静默跳转，同时切换终端和下方文件列表。
  终端菜单下载始终询问本地保存目录，无论下方文件面板是否已展开。
  嵌套 SSH、更换提示符身份或全屏程序中禁止终端文件操作；后台结果及点击菜单时
  再次检查，避免使用外层服务器的连接处理内层路径。

输出关联到产生它的命令和历史工作目录。`ls`/`ll`/`la` 的单个目录参数支持绝对路径、
相对路径及常见选项：在 `/a` 执行 `ls /b` 时，裸文件名按 `/b` 验证，不回退到 `/a`。
多目录、递归、变量/通配符及复杂管道命令无法可靠确定来源时，提示使用完整路径；
不会继续猜测同名文件。已明确的完整路径仍可操作。付费缓存只复用已经验证过的
命令相关路径，不直接用历史工作目录猜测裸名字。

文件夹导航只改变文件浏览区。脚本和日志操作明确请求终端命令：确认终端
空闲时发送，否则准备到输入框；已有草稿不覆盖。路径及参数用 shlex 引用，
拒绝控制字符。没有新增文件列表的快捷键，避免抢占终端输入。

## 文件操作

新建和重命名不覆盖已有名字。删除先明确确认，文件夹会递归删除内部内容，
不跟随链接进入其目标。删除列表过长时显示总数量。根目录和不明确路径拒绝。

远端文件剪贴板使用专用 MIME 和连接标记，与复制路径文本区分；共享窗口
可使用同一连接的剪贴板。断开重连或跨连接不能把旧剪贴板操作发到新服务器。
剪切项目文字变灰，操作完成后恢复；部分移动成功只移除成功项，剩余项保留。

粘贴先在后台检查：拒绝原位置、自身子目录、同时选择父目录及内部项目、
同批同名目标。冲突提供替换、保留两个、跳过、取消及应用到后续冲突。
保留两个预留批次中其他目标名称，避免同批次再次撞名。

复制通过独立、非 PTY 的 SSH channel 执行 `cp -a --`，先写服务器暂存目录，
再用 SFTP 发布到目标；不把数据通过终端或 UI 中转。需要远端提供 `cp -a`，
单次复制命令期限 300 秒。移动使用 SFTP rename，不自动跨文件系统复制后删源。
替换时先暂存目标原内容，发布失败尝试恢复；发布成功后清理旧内容和暂存区。
网络断开、取消或清理失败时可能留下私有命名的临时目录，UI 和日志会提供路径。
不自动重试不确定的远端修改，已完成的条目不整体回滚。

所有网络读写放后台。工作区共享一个文件操作控制器，每次一项，进度窗可取消；
传输队列与文件操作分离，已有传输不被重建。操作结束或部分失败后，通知所有
工作区刷新受影响目录和展开的树分支，并使付费页面缓存、悬停快照失效。
成功的新建、重命名或粘贴仅在当前目录中选中对应条目，不强制跳回旧目录。
现有日志模块记录操作名称、路径和结果，不记录文件内容。

## 远端编辑

独立编辑窗口读取普通文本，最大 4 MiB；支持 UTF-8、UTF-8 BOM、UTF-16 BOM、
GB18030，保存保留原编码和换行。二进制或过大文件请用下载操作。

读取、保存及另存本地的写入在后台进行。保存前比较原始字节，发布前再比较
内容和权限/属主；检测到变化不覆盖，保留编辑内容供另存本地。保存使用同目录
临时文件及服务器 posix_rename 扩展，保留权限和属主；服务器不支持安全发布或
无法保持属性时报告失败，不用先删除旧文件的方式覆盖。

编辑器支持保存按钮、Ctrl+S、另存本地。关闭编辑器、Shell 标签或程序时检查
未保存修改，可保存、放弃或取消。旧连接编辑器不能保存到重新连接后的服务器。

## 文件职责

- `context_menu.py`：上下文数据和动态菜单生成。
- `file_operations/controller.py`：单工作任务、取消、结果信号及日志。
- `file_operations/backend.py`：新建、重命名、删除、权限及粘贴前检/执行。
- `file_operations/actions.py`：弹窗、剪贴板、编辑器和命令请求的 GUI 编排。
- `file_operations/terminal_menu.py`：终端与命令输入框的异步路径菜单。
- `file_operations/translations.py`：已有六种 UI 语言的新增文案。
- `clipboard.py`：当前连接的远端文件剪贴板。
- `listing.py`、`navigation.py`：解析单目标列表命令及后台路径确认。
- `editor/backend.py`、`editor/dialog.py`：文本读写与独立窗口。
- `browser.py`、`directory_tree.py`：三处菜单入口；`file_page.py`：剪切视觉效果。
- `workspace.py`：同步刷新、结果选中和资源关闭。
- Shell/Connection/MainWindow 的关闭接口：未保存编辑检查。

仅做源码检查；未启动项目、运行测试、打包或连接服务器验收。
